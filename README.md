# Characterization of the Frequency-Current Curve of First-Order High-Pass Neurons

[![arXiv](https://img.shields.io/badge/arXiv-2611.09508-b31b1b.svg)](https://doi.org/10.48550/arXiv.2611.09508) [![Julia](https://img.shields.io/badge/Julia-1.13.1-9558B2.svg?logo=julia&logoColor=white)](https://julialang.org/) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

This repository contains the code and figure sources of the paper "[Characterization of the Frequency-Current Curve of First-Order High-Pass Neurons](https://doi.org/10.48550/arXiv.2611.09508)", submitted to the [European Control Conference (ECC 2027)](https://ecc27.euca-ecc.org/).

A first-order high-pass (HP) neuron is a static sigmoid in positive feedback with a first-order high-pass filter. The paper studies the limit cycles of first-order HP neurons and develops a formula to compute the frequency-current (FI) curve, i.e. the tonic spiking frequency as a function of the input, without simulation. The code below evaluates this formula, compares it with simulations, and produces the figures of the paper.

## Repository structure

```text
.
├── Code/
│   ├── FI_curve_compute.jl       # Compute FI curve from the paper's formula and from simulation
│   ├── RDP.jl                    # Ramer–Douglas–Peucker algorithm (reduces the number of points to plot)
│   ├── FI_curve_example.ipynb    # generates and exports the data of Figures 3 and 4
│   ├── Project.toml              # Julia dependencies
│   └── Manifest.toml             # exact versions of the dependencies
└── Figures/
    ├── figN_<name>/              # one subdirectory per figure
    │   ├── main.tex              # TikZ/PGFplots code of the figure
    │   └── data/                 # (optional) CSV data used by the figure
    ├── ...
    ├── pgfplots_style_setup.tex  # PGFplots options shared by all figures
    └── Nature-colors.sty         # color palette used in the figures
```

`RDP.jl` implements the [Ramer–Douglas–Peucker algorithm](https://en.wikipedia.org/wiki/Ramer%E2%80%93Douglas%E2%80%93Peucker_algorithm). It is used to downsample the simulated curves (to keep the figure files small). It was generated by Claude Opus 5.5.

`Nature-colors.sty` is a LaTeX implementation of Atsuya Watanabe's [Nature Color Palette](https://github.com/atsuyaw/NatureColorPalette), which is colorblind-friendly.

## Reproducing the results

### Data (Figures 3 and 4)

Tested with Julia version 1.13.1. Install the dependencies with

```bash
cd Code
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

then run `FI_curve_example.ipynb` (e.g. with Jupyter + IJulia, or VS Code). 

### Figures

Each figure compiles independently:

```bash
cd Figures/figN_<name>
pdflatex main.tex
```
